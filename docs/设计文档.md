# 《丹阁》游戏设计文档

> 一款玄幻题材的网页 2D 模拟经营游戏。玩家扮演初出茅庐的丹师，在城南开一间丹药铺子，
> 靠采药、炼丹、接单、修炼一步步走到丹道大成。

---

## 一、设计定位

| 项目 | 内容 |
|---|---|
| 类型 | 单机模拟经营 + 轻 Roguelike 探险 |
| 题材 | 东方玄幻 · 丹药修行 |
| 单局时长 | 无固定终局，可长期经营；300 日内可推到元婴～化神期 |
| 目标体验 | 「慢节奏的积累感」——药材要一味味采，丹药要一炉炉炼，境界要一步步熬 |
| 操作重心 | 决策（炼什么、接哪单、何时闭关），而非操作 |

**核心情绪**：开局身无长物，只有一间空铺子；到后来药材满仓、订单应接不暇、一炉能出极品 —— 全程用**资源与时间的双重约束**制造"精打细算"的乐趣。

---

## 二、核心循环

```
        ┌──────────────────────────────────────────┐
        │                                          │
   ①秘境采药 ──→ ②炼丹 ──→ ③接单/零售 ──→ ④灵石/声望
        ↑           ↑            │                │
        │           │            │                ↓
        └─── 灵石 ←─┴────── ⑤修炼突破 ←────── 顾客/收购
```

- **① 秘境**：时间与行动力换材料（唯一的无本生意）
- **② 炼丹**：材料 + 火候决策换丹药（品质决定售价与药效）
- **③ 交付**：丹药换灵石（委托为主、零售为辅）
- **④ 收入**：灵石要分给打坐、悟道、买药、升级丹炉，处处是取舍
- **⑤ 突破**：境界既是战力，也是解锁新丹方与新秘境的门槛

**闭环张力**：想突破就要打坐（耗灵石），想赚灵石就要下秘境（耗时间与气血），
而下秘境需要战力（来自境界）。三条路互相牵制，玩家始终在"钱不够"与"时间不够"之间做选择。

## 三、系统设计

### 3.1 境界与成长（22 级）

```
凡人 → 炼气期 → 筑基初期/中期/后期 → 金丹初/中/后 → 元婴初/中/后
     → 化神初/中/后 → 炼虚初/中/后 → 合体初/中/后 → 大乘期 → 渡劫期
```

- **炼气期不分层**：一次突破直入筑基，前期节奏清爽，也让第一次突破有"跃迁感"（属性 ×6）
- **属性查表**（`D.STATS`）：数值锚定在大境界上，与各秘境妖兽强度一一对应
- **成长节奏**：每级约 18~25 天打坐，全程理论 466 天
- **突破风险**：成功率 `0.93 - 等级×0.022`（炼气期 91% → 渡劫期 47%）；失败损失 35% 修为，但不会身死
- **丹药永久加成跨境界保留**：突破时按「新境界基础值 + 累积加成」计算，辛辛苦苦服的洗髓丹不会白费

### 3.2 秘境探险

- **6 处秘境**，按境界解锁：青木林 → 火云谷 → 寒潭幽谷 → 万蛊沼 → 玄天雷渊 → 上古遗迹
- **行动力制**：`40 + 境界×4`，每走一格 -1；耗尽时二选一 —— 带着收获返回，或就地歇息一日恢复 60%
- **地图要素**：灵草（采药）、宝箱（稀有材料）、灵泉（回血 42%）、妖兽（战斗）、金色光圈（出口）
- **迷雾视野**：随境界提升视野半径（青木林 4.5 → 上古遗迹 2.8），高级秘境更难摸清地形
- **战斗**：极简回合制（出击 / 蓄力一击 / 丹 / 逃走），单场耗血 13%~43%，靠灵泉维持续航
- **妖兽产出**：只掉 **材料与灵石**，不给修为
- **重置秘境**：路不好走时就当这趟没进来过 —— 重掷地形、行动力回满、本次收获全部退回

**设计意图**：秘境是"时间换资源"的唯一途径，也是战斗系统的载体。
行动力上限让每次探索都是**有边界的规划**（这次要采什么、打几只怪），而不是无限刷。

**为什么打怪不给修为**：初版一只妖兽给同级打坐 2~4 天的修为，一趟秘境刷 6~11 只怪
就够**连着突破好几次**；即便后来压到半日/只，四~五趟秘境仍能顶一次突破，
打坐与丹药始终是被架空的。索性彻底拿掉 —— 秘境的产出就是**钱与药材**，
修为只能从打坐、服丹、宝箱与战败感悟里来。两套系统各司其职：
**秘境管赚钱，静室管修行**，玩家没法靠刷本绕过"攒钱→闭关"这道坎。

**三重地形保障**：① 元胞自动机生成洞穴地貌（成片的岩体与空地，死胡同率仅 0.2%）；
② 连通性校验（走不到的空地一律填实）；③ 出口按实际步数选在 12~20 步处（`行动力 44` 够走个来回还有余）。
在外加「重置秘境」这条兜底 —— **地图学上无死局，不等于玩家觉得好走**。

**为什么重置要"退回收获"**：如果只花行动力就能重掷、收获还留着，玩家会忍不住反复重掷去刷采集点。
让重置变成一笔**净零的交易**（进去时的行动力、出来时的收获，两边都抹平），
它就纯粹是"走不通时的退路"，而不是一条变相收益。

### 3.3 炼丹

三层决策：

| 决策层 | 选项 | 权衡 |
|---|---|---|
| 炼什么 | 16 张丹方（按境界解锁） | 材料成本 vs 售价/订单需求 |
| 火候 | 文火 / 中火 / 武火 / 急火 | 成功率 vs 品质 vs 工期 |
| 何时炼 | 随时（推进日期） | 时间也是资源 |

**概率模型**（两步掷骰）：
1. 先掷成败：`成功率 = 0.72 + 丹炉加成 + 天赋 + 境界压制`（clamp 15%~98%）
2. 成丹后掷品质：`roll = rand()×1.35 + 品质加成`，阈值 0.58 / 1.00 / 1.30 对应 中/上/极品

**火候实测概率**（无丹炉无天赋，界面实时显示）：

| 火候 | 成功率 | 下品 | 中品 | 上品 | 极品 |
|---|---|---|---|---|---|
| 文火慢炼 | 92% | 46% | 29% | 17% | **0%** |
| 中火守正 | 72% | 31% | 22% | 16% | 3% |
| 武火猛攻 | 50% | 13% | 16% | 11% | **10%** |
| 急火抢时 | 62% | 29% | 19% | 14% | 0% |

**设计意图**：文火不会失败但永远出不了极品；武火一半会炸炉却有 10% 极品率。
这个"稳"与"赌"的张力是炼丹系统的核心乐趣。

### 3.4 经济：委托为主，零售为辅

**零售**（自动结算，保底）
- 散客只肯出公道价的 60%~98%，利薄量小
- 定位：走量攒声望，不是主要收入

**委托订单**（主动接取，主力收入，占比 60%~90%）

| | 常单 | 急单 |
|---|---|---|
| 墙上能留 | 12~20 日 | **3~6 日**（不接就被揭走） |
| 接单后时限 | 5~11 日 | **6~9 日**（应承下来就给足功夫） |
| 报价 | 市价 ×1.5~1.9 | 市价 ×2.5~3.3 |
| 误期 | 不扣声望，只是少赚 | **失约扣 2 点声望** |
| 附加 | — | 感悟谢礼 |

**两阶段状态机**：`open`（贴墙上，不计时）→ 玩家点「接下」→ `taken`（移入手上，开始倒计时）。
手上最多同时经手 3 张，墙上最多 8 张。

**设计意图**：
- 玩家去闭关/探险时订单会自己攒着，回来有一堆选择 —— 制造"生意兴隆"的正反馈
- 急单**墙上留不久但接后给足时间**：逼玩家快速决策，但不惩罚接了单的人
- 常单误期不扣声望、急单失约才扣，让"风险"与"承诺"挂钩，而非无差别惩罚

### 3.5 灵石开销（处处是取舍）

| 开销 | 公式 | 说明 |
|---|---|---|
| 打坐布阵 | `(40 + 境界×8 + 境界²×1.5) × 天数` | 每日都要烧，灵石见底就坐不下去 |
| 焚香悟道 | `200 + 境界×30` | 一次换 4~7 感悟 |
| 参悟天赋 | `(60 + 境界×8) × (层数+1)^1.2` | 与感悟**双重消耗** |
| 市集买药 | 行价 ×**2.5** | 应急才用 |
| 丹炉/店面 | 一次性大额（600 → 30,000） | 长期投资 |

**打坐日耗的标尺**：**一枚上品丹的进项 ≈ 同级 2~3 天的开销**。
炼气期聚气丹上品卖 108 灵石，日耗 50 —— 正好两天多。
这条标尺让"炼丹赚钱"与"闭关烧钱"直接挂上钩：想多坐一天，就得多卖一枚丹。

| 境界 | 日耗 | 突破一境总开销 |
|---|---|---|
| 炼气期 | 50 | 950 |
| 金丹初期 | 118 | 3,068 |
| 化神中期 | 352 | 8,800 |
| 合体初期 | 610 | 14,030 |

**关键平衡**：所有 16 张丹方"买料再零售"都亏本（投入产出比 0.57~0.60）。
这是刻意的 —— 逼玩家**自己下秘境采药**，把"探索"钉死在核心循环里。
同时保证秘境日收入 ≥ 打坐日耗 × 3（最紧的上古遗迹为 3.2×），不会卡死。

### 3.6 丹道感悟与天赋

- **获取**：成丹（下品+1 → 极品+4）、秘境探索、交委托、静坐悟道、境界突破
- **7 条天赋**：火候精熟 / 丹心通明 / 一炉双丹 / 巧舌如簧 / 悟道于静 / 淬体秘法 / 医者仁心
- **消耗**：感悟 `cost × (层数+1)^1.35` + 灵石 `(60+境界×8) × (层数+1)^1.2`
- **总量**：七门点满需 1,392 感悟 + 数万灵石（渡劫期点满约 8.2 万）

**设计意图**：天赋是"长线目标"，不是"随手点点"。
双消耗让玩家在"点天赋"与"冲境界"之间做真实的取舍。

## 五、设计取舍记录

| 决策 | 原因 |
|---|---|
| 炼气期不分层 | 原九层节奏拖沓，前 9 次突破只有数值变化，缺乏解锁反馈 |
| 订单改为主动接取 | 初版订单自动累积、自动计时，玩家没参与感；改为"墙上待接 → 手动接下才计时" |
| 急单墙短接长 | 让急单"紧迫"体现在**决策时机**而非**执行难度**上 |
| 买药价格 2.5 倍 | 初版 1.25 倍时，买料炼丹反而赚钱，秘境探索失去意义 |
| 打坐耗灵石 | 初版灵石只进不出，中期开始钱多得没处花，失去经营压力 |
| 天赋双消耗 | 感悟单独消耗时，天赋早早满级，长线目标消失 |
| 突破保留丹药加成 | 初版突破会重置属性，把永久丹药的投入抹掉，玩家会觉得被欺骗 |
| 行动力耗尽弹选择 | 初版直接踢出秘境，玩家采到一半被强制中断，体验粗暴 |
| 出口按步数选在中距 | 初版把出口放在最远处（约 30 步），行动力 44 走过去就快没余量探索了 |
| 地形平滑 + 重置秘境 | 连通性只是数学保证，"路好不好走"是体感问题；平滑减死胡同，重置给主观兜底 |
| 地形改用元胞自动机 | 斑块叠加法生成的路网零碎、障碍多堆在边缘（`test_map.js` 实测死胡同 4%）；元胞自动机长出的地貌成片，降到 0.2% |
| 重置＝行动力回满 + 收获退回 | 重置的本意是"进去发现走不通，那就当没来过"；保留收获反而会诱使玩家反复重掷刷资源 |
| 实体按象限轮转放置 | 纯顺序填格会扎堆在地图一角，纯随机会三五成群；象限轮转 + 间隔约束才能铺得均匀 |
| 妖兽不给修为 | 初版打怪给同级 2~4 天打坐的修为，一趟秘境够突破好几次；先砍到 1/7 仍嫌多，索性取消 —— 秘境管赚钱，静室管修行 |
| 打坐日耗按"上品丹≈2~3 天"定标 | 初版日耗 9~69 灵石，交几张单就能买通一整条境界线；按"一枚上品丹够坐两天多"重设，灵石才真正成为瓶颈 |
| 状态栏显示灵力 | 蓄力一击要耗灵力，但界面上看不到，玩家无从判断该不该用 |
| 手机只做基础适配 | 游戏以桌面 web 为主（信息密度、悬停提示都按鼠标设计）；手机端只保证「能用、不乱、点得到」，不追求等比还原 |
| 竖屏版式按"宽高比"判定 | "适配手机"的实际诉求就是适配竖屏；与其按设备猜，不如按形状判 —— 电脑窗口拉成竖条同样走竖版，在电脑上就能直观预览 |
| 竖屏给秘境加方向盘 | 22×14 格的地图在竖屏下每格只有十几像素，手指既点不准又挡住视线；横屏/桌面不给，键盘鼠标本来就顺手 |
| 方向盘排成一排 | 十字布局要占两行高度，而竖屏最缺的就是高度；一排 `◀ ▲ ▼ ▶` 够用又省地方 |
| 地图始终完整可见 | 22:14 的地图按宽度铺满，在横屏/扁窗口里会比可视区还高，玩家得滚动才能看全 —— 秘境里最烦的事。改为按可用空间等比缩放（宽够就铺满，高不够就以高度为准），代价是宽屏下左右留白 |
| 战斗改为全屏模态 | 面板原先贴在 canvas 上，窄屏会被裁掉按钮（点不到攻击）；改为挂 body 级的全屏层，面板相对视口居中，任何窗口尺寸都能操作 |

## 六、后续可扩展方向

- **多店铺/分号**：在不同城池开分店，雇人看店
- **丹方残卷**：秘境中掉落残卷，拼合才得完整丹方
- **顾客声望线**：同一顾客多次成交后成为老主顾，给专属高价订单
- **季节/节气事件**：如"丹会"期间订单翻倍、"疫病"期间疗伤丹脱销
- **师徒系统**：收徒、传艺，弟子帮忙采药或看店
- **妖兽图鉴与材料溯源**：已搜集的材料显示来历
